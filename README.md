# NSTA GitHub Pages Website Template

Editable static website template for the North Sydney Transport Association.

## How to use on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Wait for GitHub to publish the site.

## Editing

- Main text and page sections: edit `index.html`
- Colours, layout, fonts and spacing: edit `styles.css`
- Mobile menu behaviour: edit `script.js`

## Suggested future pages

You can later split the single-page template into:
- `publications.html`
- `projects.html`
- `events.html`
- `about.html`
- `contact.html`
